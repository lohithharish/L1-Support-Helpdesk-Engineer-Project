# 🎫 ServiceNow Incident Management Portfolio

## 📌 Overview

This repository contains sample ServiceNow incident tickets created to demonstrate practical L1 IT Support and Service Desk operations following ITIL incident management practices.

The incidents showcase ticket creation, troubleshooting, escalation, SLA tracking, user communication, resolution, and closure processes. The tickets were resolved within defined SLAs and documented using ServiceNow.  

---

## 📂 Included Incidents

### 🔐 Password Reset Ticket

**Incident Type:** User Account Support

**Issue:**
User was unable to log in due to incorrect credentials.

**Actions Performed:**

* Verified user identity
* Reset user password
* Updated ticket with resolution notes
* Closed incident after confirmation

**Skills Demonstrated:**

* Account Administration
* User Support
* ServiceNow Incident Handling
* SLA Compliance

📄 File: `Password reset ticket (servicenow).pdf` 

---

### 🌐 VPN Access Issue

**Incident Type:** Network Support

**Issue:**
User was unable to connect to VPN because the account was disabled.

**Actions Performed:**

* Validated VPN error
* Performed initial troubleshooting
* Escalated to L2 Network Team
* Confirmed successful restoration of VPN access

**Skills Demonstrated:**

* VPN Troubleshooting
* Incident Escalation
* L1 Support Process
* ITIL Workflow

📄 File: `VPN Issue.pdf`
