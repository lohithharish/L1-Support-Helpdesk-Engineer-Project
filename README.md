# IT Service Desk & Incident Management System

## Overview

This project demonstrates real-world IT Service Desk operations using ServiceNow and Active Directory, simulating the daily responsibilities of an L1 Support Engineer in an enterprise environment.

The project covers the complete incident management lifecycle, SLA monitoring, ticket escalation procedures, Active Directory administration, and troubleshooting workflows commonly followed by Service Desk and IT Help Desk teams.

---

## Project Objectives

* Simulate real-world IT Service Desk operations
* Manage incidents using ServiceNow
* Perform user administration using Active Directory
* Configure and monitor Service Level Agreements (SLAs)
* Document troubleshooting and resolution activities
* Demonstrate escalation workflows from L1 to L2 Support
* Build a portfolio project aligned with industry ITSM practices
